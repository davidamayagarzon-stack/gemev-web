# GEMEV — sitio web

Primera versión estática inspirada en las capturas proporcionadas de Airo Builder.

## Archivos

- `index.html` — estructura y contenido.
- `style.css` — diseño visual y responsive.
- `script.js` — menú móvil y año automático.
- `assets/gemev-logo.png` — logo provisional recortado de la captura.

## Próximos pasos

1. Sustituir `assets/gemev-logo.png` por el archivo original del logo en alta resolución.
2. Ajustar textos reales, cifras, sectores y datos de contacto.
3. Añadir logos reales de empresas afiliadas.
4. Añadir imágenes/eventos cuando estén disponibles.
5. Publicar en GitHub Pages y conectar `gemev.co` mediante DNS de GoDaddy.


## Versión 2

Se refinó la jerarquía visual, el ritmo vertical, las transiciones entre secciones,
el comportamiento de las tarjetas y la adaptación móvil para acercar el resultado
al lenguaje visual de las referencias proporcionadas.
